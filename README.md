# 📊 Sales Dashboard Analysis (Superstore)

## 📌 Overview

This project analyzes Superstore sales data and builds an interactive Power BI dashboard to generate business insights and forecasts.

## 🛠 Tools & Technologies

* Power BI
* Excel / CSV

## 📁 Dataset

Superstore Sales Dataset including sales, profit, quantity, and regional data.

## 📊 Dashboard Features

* Sales & Profit overview
* Category & Sub-category analysis
* Region-wise performance
* Payment mode insights
* Shipping mode analysis
* 15 Days Sales Forecast
* dasboard preview:-<img width="1326" height="742" alt="image" src="https://github.com/user-attachments/assets/108b3971-5acc-4a9b-92a5-cb8989c1ff89" />


## 🔍 Key Insights

* Technology and Office Supplies contribute highest sales
* COD is the most used payment method
* West region shows highest sales contribution
* Seasonal trends observed in monthly sales

## 🚀 Conclusion

The dashboard helps businesses monitor performance, identify trends, and make data-driven decisions.
